## 修改

- 城市获取失败的实机原因：IPWhois 成功，Open-Meteo 的搜索和天气请求因 API 22 缺少信任根而失败。新增官方 ISRG Root X1，仅供兼容构建 API 22 的两个 HTTPS 天气域名验证证书链；保留主机名验证，不修改系统信任库，标准版不走该路径。
- 自动城市在天气请求前独立保存，不再因天气失败而丢失城市结果；新增“立即重试”和可区分的 TLS、DNS、超时提示，不回显服务端详情。
- 开机选项恢复至“设置 → 电视与启动 → 开机自动进入”，不再放在 Home 页。只调整界面，沿用现有启动桥及 `legacy-home/boot` 偏好；Home 和开机开关仍独立。
- MiTV3 的 Home 页移除无效的“打开系统默认桌面设置”入口，解释遥控器无法操作左侧圆圈、保存默认记录也被固件绕过，直接使用兼容开关。标准版原生设置入口保留。
- 首页显示名称由“网易 Filmly”改为“网易爆米花”，包名、应用入口及已保存顺序不变。
- 调整 Home、开机和城市子页的返回路径与父级标题。
